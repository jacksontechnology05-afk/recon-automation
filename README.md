# JACKSON SECURITY ASSESSMENT FRAMEWORK

## Overview

Jackson Security Assessment Framework is a Python-based cybersecurity reconnaissance, OSINT, exposure assessment, vulnerability validation, and compliance-oriented security framework developed for:

- Ethical Hackers
- Penetration Testers
- Security Analysts
- Vulnerability Assessment Teams
- Cybersecurity Researchers

The framework automates reconnaissance, attack surface analysis, security validation, and basic vulnerability assessment tasks during authorized security engagements.

# Installation

## Clone Repository

```bash
git clone https://github.com/jacksontechnology05-afk/recon-automation.git
```

---

## Navigate Into Project Directory

```bash
cd recon-automation
```

---

# Install Dependencies

## Kali Linux (2024/2025)

```bash
pip3 install requests python-whois dnspython --break-system-packages
```

---

## Other Linux Distributions

```bash
pip3 install requests python-whois dnspython
```

---

# Run Framework

```bash
python3 main.py
```
